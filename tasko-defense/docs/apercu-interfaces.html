Tasko Defense — aperçu des interfaces

Boîte à outils de sécurité défensive, cadrée par un mandat.

Tasko Defense est un outil en ligne de commande : il n'a pas d'interface graphique. Les captures ci-dessous sont des sorties réelles du terminal (exécutées en local, avec de faux outils sur 127.0.0.1, aucun scan réel).
Aide générale exit 0

Le point d'entrée unique : toutes les sous-commandes.

$ python3 -m tasko.cli --help
usage: tasko [-h] [--version]
             {verifier,info,nouveau-mandat,journaliser,journal,rapport,poc,poc-brouillon,purple,preuve}
             ...

Tasko Defense — outils cadrés par mandat

positional arguments:
  {verifier,info,nouveau-mandat,journaliser,journal,rapport,poc,poc-brouillon,purple,preuve}
    verifier            autorise (ou non) un test sur une cible
    info                résume un mandat
    nouveau-mandat      crée un mandat machine (non signé) depuis le gabarit
    journaliser         ajoute une entrée au journal des tests
    journal             restitue le journal en Annexe C (Markdown)
    rapport             agrège un dossier de scans en rapport client
    poc                 documente et scelle une PoC sous Annexe D (n'exécute
                        rien)
    poc-brouillon       génère un brouillon de PoC pré-rempli depuis un
                        finding de scan
    purple              rejoue des sondes inertes pour valider la détection
    preuve              décode/désobfusque un artefact détenu (défensif, hors
                        ligne)

options:
  -h, --help            show this help message and exit
  --version             show program's version number and exit
